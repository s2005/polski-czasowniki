# Ćwiczenia z polskiego

Упражнения по польскому для тех, кто учит язык с русского: спряжение глаголов в настоящем времени (czas teraźniejszy) и винительный падеж. Работает в браузере, на телефоне и планшете, в том числе без интернета.

**Открыть:** https://s2005.github.io/polski-czasowniki/

Рядом — отдельное приложение **Ile słów?** для подсчёта слов в письменной работе: https://s2005.github.io/polski-czasowniki/slowa/

## Режимы

| Режим | Что делать |
|---|---|
| **Предложения** | Вставить нужную форму глагола в предложение. Наборы 7 A–D и 8 A–B, предложения с новыми глаголами и все наборы вместе. |
| **Формы** | Дано лицо и глагол, нужна форма. Можно вводить её с клавиатуры или выбирать из 4 вариантов. Группы глаголов можно отфильтровать. |
| **Таблица** | Заполнить все 6 форм выбранного глагола. |
| **Винительный** | Поставить существительное в нужный падеж: винительный (biernik) после *mam, lubię, kupuję, widzę, proszę, czekam na…* или именительный (mianownik) после *to jest, gdzie jest, dla mnie*. Темы: заказ в кафе, продукты, люди и животные, одежда, дом и кухня, город и транспорт, вещи, чтение и кино (268 слов из словаря учебника POLSKI krok po kroku 1). Темы и падеж можно выбрать. Правило с примерами — в раскрывающемся блоке. |
| **Ошибки** | Повторить ошибки: формы глаголов и слова из «Винительного» (падеж, в котором была ошибка). Если есть ошибки обоих видов, можно выбрать, что повторять. Каждая ошибка добавляет +1, каждый верный ответ снимает 1; при нуле форма или слово уходит из списка. |
| **Шпаргалка** | Правила групп и спряжение выбранного глагола; окончания выделены цветом. |

### Прогресс

- В «Формах», «Предложениях» и «Винительном» предлагаются только новые задания и задания с ошибками.
- Выученным считается задание, решённое верно с первой попытки (или исправленное в «Ошибках» до нуля). Ошибка в выученном возвращает его в задания.
- Полоса показывает, сколько выучено из выбранных групп, наборов или тем. Когда всё выучено, задания больше не предлагаются, пока прогресс не сброшен кнопкой «Сбросить прогресс».

### Как проверяются ответы

- Если введена форма другого лица, тренажёр так и говорит, например: «это форма для *my*, нужна для *oni*».
- Если ошибка только в польской букве (*e* вместо *ę*), ответ засчитывается как «почти».
- После ошибки появляется разбор, после чего ответ можно исправить и проверить ещё раз. В счёт идёт только первая попытка.
- Внизу экрана есть кнопки для букв **ą ć ę ł ń ó ś ź ż**. Они видны только там, где есть поле ввода.

## Группы глаголов

| Группа | Пример | Окончания (ja … oni) |
|---|---|---|
| A · -ować | pracować | -uję, -ujesz, -uje, -ujemy, -ujecie, -ują |
| B · -ać | czytać | -m, -sz, —, -my, -cie, -ją |
| C · -ić, -yć, -eć | lubić, tańczyć, woleć | -ę/-ię, -isz/-ysz, -i/-y, -imy/-ymy, -icie/-ycie, -ą/-ią |
| D · -ę, -esz | pisać, móc, chcieć | -ę, -esz, -e, -emy, -ecie, -ą |
| Особые | być, mieć, jeść, wiedzieć, rozumieć, umieć | запоминаются целиком |

Всего 75 глаголов.

## Установка на iPhone / iPad

1. Открыть https://s2005.github.io/polski-czasowniki/ в **Safari**.
2. Нажать «Поделиться», затем «На экран „Домой"» и «Добавить».

Тренажёр откроется на весь экран как приложение и будет работать без интернета.

На Android откройте ссылку в Chrome, затем в меню выберите «Установить приложение» или «Добавить на главный экран».

> Ошибки и прогресс хранятся локально, в браузере устройства, и между устройствами не синхронизируются. Синхронизация через облако и статистика по дням работают только в версии внутри Claude.

## Структура

```
index.html             — весь тренажёр: разметка, стили, данные и логика
manifest.webmanifest   — описание приложения (название, иконки, полноэкранный режим)
sw.js                  — service worker: офлайн-кэш, при наличии сети страница берётся из сети
icon-*.png             — иконки 180, 192, 512 px
slowa/                 — отдельное приложение «Ile słów?» со своими index.html, манифестом, sw.js и иконками
```

Сборка не нужна, внешних зависимостей нет (кроме шрифтов Google Fonts; без сети используются системные).

## Как добавить глагол

Список глаголов задан в массиве `VERBS` в `index.html`.

```js
A('kupować', 'покупать')            // группа A: формы строятся автоматически
B('czytać', 'читать')               // группа B: формы строятся автоматически
M('pisać', 'писать', 'D',           // остальные: все 6 форм через запятую
  'piszę, piszesz, pisze, piszemy, piszecie, piszą')
```

Предложения задаются в массиве `SETS` в формате `['Tekst ___ .', 'инфинитив', 'правильная форма']`.

Слова для режима «Винительный» задаются в объекте `BT` по темам. У темы есть фразы для biernika (`B`) и mianownika (`M`), где `___` — место для слова. Слово записывается строкой `'mianownik|biernik|тип|перевод'`; пустой biernik значит, что форма не меняется. Пятым полем можно задать свои фразы для biernika через `;`, например `'gazeta|gazetę|f|газета|Czytam ___.;Kupuję ___.'`.

Типы: `f` (женский род), `fa` (женский, склоняется как прилагательное: teściowa), `fc` (женский на согласный: sól), `ma` (мужской одушевлённый), `mA` (мужской на -a: tata), `mv` (овощи и фрукты: засчитываются обе формы, ogórek и ogórka), `mi` (мужской неодушевлённый), `n` (средний род), `pl` (множественное число), `pv` (множественное с мужчинами: rodzice → rodziców).

После изменений поменяйте версию кэша в `sw.js` (например, `czasowniki-v7` на `czasowniki-v8`; для «Ile słów?» — в `slowa/sw.js`), чтобы установленное приложение точно обновилось.

## Ile słów? — подсчёт слов

Отдельное приложение для письменной части экзамена: текст сравнивается с нужным количеством слов с допуском ±10%, видно, что посчитано как слово, ниже — правила подсчёта.

- Слово — любая группа знаков между пробелами, в которой есть буква или цифра.
- Слово через дефис (*e-mail*), сокращение (*np.*) и число цифрами (*8.00*) считаются как одно слово.
- Знаки препинания, отдельное тире и эмодзи не считаются.
- Текст и нужное количество слов хранятся локально, в браузере устройства.

Устанавливается на телефон так же, как тренажёр, по адресу https://s2005.github.io/polski-czasowniki/slowa/
